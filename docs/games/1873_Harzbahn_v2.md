=== "SR"

    ## 1. スタートオークション

    ### 対象

    - 15個の個人鉱山
    - HBE concession
    - GHE concession

    ### 手順

    1. まず「最初に購入する権利」のプレミアムを競る。最小0、以後10M刻み。
    2. 落札者が先頭、以後はパスした逆順で新しい手番順を作る。
    3. 落札者は、鉱山またはconcessionを1つ購入する。支払額は額面/最低価格 + プレミアム。
    4. 以後、手番順に「購入」または「パス」。
    5. 全員が連続パスしたらプレミアムを10M下げる。
    6. 全対象が購入される、またはプレミアム0で全員連続パスしたら終了。

    例: Aが最初の権利を落札し、B、C、Dの順にパスしたなら、新しい手番順はA、D、C、B。以後この順で購入/パスし、全員が連続パスするたびにプレミアムを10M下げる。

    ### 未購入品

    - 未購入鉱山は閉鎖。以後、プレイヤーは買えない。公開鉱山会社だけが額面で購入して再開できる。
    - 未購入concessionは次回以降のARに戻る。
    - 購入したconcessionは、直後のSRで鉄道会社設立に使わないとSR終了時に没収される。

    ### プレイヤーズガイド由来の初期評価メモ

    - \#12 Blankenburg と HBE concession は最重要候補。4人戦ではプレミアム50-80M程度が目安。
    - \#15 Thale は開始時から国営路線に接続済み。#14 Zorge は早期接続しやすい。目安30-50M。
    - \#11 Tanne はF3敷設でSHE/KEZの展開に影響できる。目安20-30M。
    - \#8 Netzkater はI8敷設でNWEを早期活性化できる。
    - その他鉱山やGHE concessionは0-20M程度の低プレミアム候補になりやすい。


    ## 2. AR（通常オークション）

    - Start Auction後のARでは、活性化済みで未所有のconcessionや、管財会社のpurchase optionを競る。
    - 現在の手番順で、各プレイヤーは「対象を1つ競売にかける」か「パス」。
    - 競売にかけるプレイヤーは開始ビッドを提示する。開始ビッドは100M以上、10M刻み。
    - 競売にかけた対象は通常の競りで落札。最低上げ幅10M。
    - 一度パスしたプレイヤーは、その対象の競りには戻れない。
    - 全員が対象を競売にかける機会を連続パス、または対象がなくなったらAR終了。


    ## 3. SR（株式ラウンド）

    各手番では、先に任意数の株式を売却し、その後に以下のいずれか1アクションを行う。

    - 株式購入
    - 鉄道会社設立（4.1。concession没収に注意）
    - 公開鉱山会社設立（4.2。HWだけSR1例外あり）
    - 管財会社のpurchase option行使（11.4）
    - パス

    SR終了時、現金の多い順に次TRの手番順を決める。同額なら従前の相対順を維持。

    ### 3.1 株式売却

    - SR1では売却不可。
    - 1社の株はまとめて売却してから、別会社の株を売る。
    - 売却株はBank Poolへ。
    - 受取額は現在株価。ただし、未運営会社の株は1段階低い株価で受け取る。
    - 売却1枚ごとに株価1段階下落。
    - 例外:
      - 未運営会社は、売却しても株価下落なし。
      - 株価は50未満にならない。
      - MHEは5列車獲得後、売却でも配当でも株価変動しない。
    - 鉄道会社の社長は、その会社が compulsory train を買うか破産するまで交代しない。またその間、社長は20%未満になる売却不可。
    - Bank Poolには最大80%まで入りうる。管財会社は100%がBank Pool。

    ### 3.2 株式購入

    - 1アクションで1株購入。
    - 購入条件:
      - 会社が管財下でない。
      - 購入可能な株がある。
      - このSR中に同社株を売っていない。
    - Bank Pool株は銀行へ支払い。
    - Initial Offering株:
      - 会社が未運営なら、支払先は銀行。会社浮上時に銀行から全額資本化される。
      - 会社が運営済みで新株発行による株なら、支払先は会社。
    - MHE株は常にBank Pool扱い。

    ### 3.3 SR中の判断メモ

    - concessionを持っているなら、このSRで鉄道会社を設立するか判断する。設立しないconcessionはSR終了時に戻る。
    - 個人鉱山2つを組み合わせられるなら、公開鉱山会社設立を検討する。SR1は原則不可、HWのみ例外。
    - 同じSR中に売った会社の株は買い戻せない。


    ## 4. 会社設立

    ### 4.1 鉄道会社の設立

    条件: 対応するconcessionを所有し、少なくとも1株を買えること。

    注意: concessionは、獲得した直後のSRで設立に使わなければSR終了時に没収される。

    手順:

    1. 初期株価を選ぶ。候補は 120 / 150 / 190 / 240 / 300。
    2. 株価マーカーを置く。同値に既存マーカーがあれば下に置く。
    3. 20%株5枚をInitial Offeringに置く。
    4. 設立者は1株を即購入。資金があれば同アクションで2株目も購入可。

    浮上:

    - Initial Offeringから3枚目の20%株が買われたら60%浮上。
    - 会社は現在株価 x 5 を銀行から受け取る。
    - 残り2枚の20%株はBank Poolへ移る。
    - 全てのホーム駅を無料で即配置する。
    - 次ORから運営。

    ### 4.2 公開鉱山会社の設立

    通常はSR2以降。例外としてHWは条件を満たせばSR1から可。

    条件:

    - 手番プレイヤーが個人鉱山を少なくとも1つ所有。
    - 合併に使える別の個人鉱山がある。
    - 未設立の公開鉱山会社チャーターがある。
    - 閉鎖鉱山は設立材料にできない。

    手順:

    1. 未設立の公開鉱山会社を選ぶ。
    2. 2つの個人鉱山を選ぶ。片方は手番プレイヤー所有でなければならない。もう片方は他プレイヤー所有でもよいが同意が必要。
    3. 初期株価は2鉱山の額面平均を、株価表の有効値へ切り下げ。
    4. 鉱山証書、鉱山資金、switcherを新会社に移す。machine markerは各鉱山に残る。
    5. 各鉱山の旧所有者は50%株を1枚受け取る。
    6. 手番プレイヤーが初代社長。

    ### 4.3 Harzer Werke AG（HW）

    - HWは公開鉱山会社だが、特別ルールがある。
    - SR1で設立できるのは #12 Blankenburg 所有者のみ。#12を初期鉱山の1つにする必要がある。この権利はSR1で使わないと失効。
    - HW設立に使う2鉱山は、常にVor-Harzer鉱山でなければならない。
    - SR2以降は、Vor-Harzer鉱山を所有する任意プレイヤーがHWを設立できる。#12は必須ではない。
    - HWは生産時に常に +50M の収益を得る。
    - HWが後で購入できる鉱山もVor-Harzer鉱山だけ。

    Vor-Harzer鉱山: #1, #4, #5, #6, #10, #11, #12, #14。

    ### 4.4 MHE

    - MHEは外部会社。社長は存在しない。
    - 株は10枚、初期株価120、SR1から購入可。
    - SR2以降は売却可。
    - MHEが5列車を得た後は、株価は以後固定。


=== "OR"

    ## 6. 個人鉱山のOR

    順序:

    1. 線路敷設
    2. 生産
    3. 利益分配
    4. machine/switcher購入・switcher廃棄
    5. 鉱山閉鎖

    ### 6.1 線路敷設

    - 未接続の個人鉱山は、各ORで1タイル敷設できる。フェイズ3以降はアップグレードも可。
    - 鉱山のヘクスから国営路線まで連続線路ができると接続済みになる。
    - \#15 Thaleは開始時から接続済み。
    - 他社concession route上の未建設部分に敷設して建設費を払った場合、鉱山所有者が銀行から同額を個人資金として払い戻される。
    - concession routeヘクスに敷く場合、そのrouteを完成不能にしてはならない。

    ### 6.2 生産

    - 未接続なら、鉱山カードのM1下の基礎収益のみ。machineやswitcherが大きくても増えない。
    - 接続済みなら、現在のmachine欄の収益 + switcher欄の収益。
    - フェイズ3以降、該当する維持費を差し引く。
    - 収益が維持費以下なら利益は0。
    - 維持費不足を鉱山資金で補えない場合、鉱山は強制閉鎖。

    ### 6.3 利益分配

    - 利益の50%を所有者、50%を鉱山資金へ。端数処理が必要な場合は原文に従う。

    ### 6.4 machine / switcher

    - machineは銀行からのみ購入。他社売買不可。
    - 新machineは現在より大きいサイズのみ購入可。購入時、既存machineは無料で除去。
    - machineは任意廃棄不可。
    - switcherはフェイズ2以降、銀行または他社から購入可。
    - 他社からswitcherを買う場合、価格は1M以上、額面の2倍以下。必要な維持費は売り手または買い手が購入時に支払う。
    - 個人鉱山はswitcherを1台まで。買い替え時は旧switcherを除去。
    - switcherは無料で任意廃棄可。

    ### 6.5 閉鎖

    - 個人鉱山はOR末に任意閉鎖可。
    - 鉱山資金は所有者へ。
    - 高位machineやswitcherは除去。固有の1-machineのみ残る扱い。
    - マップ上の鉱山マーカーを閉鎖面へ。
    - 以後、公開鉱山会社が額面購入するまで再開しない。


    ## 7. 公開鉱山会社のOR

    順序:

    1. 生産
    2. 利益分配
    3. 株価調整
    4. 鉱山購入
    5. machine/switcher購入・switcher廃棄
    6. 新株発行

    公開鉱山会社は線路敷設・アップグレード不可。

    ### 7.1 生産

    - 所有する全鉱山の収益合計。
    - switcherは生産時に所有鉱山間で自由に配置できる。ただし1鉱山1台まで。
    - 未接続鉱山は基礎収益のみ。接続済み鉱山はmachine + switcher。
    - 維持費を差し引く。不足を会社資金で補えない場合、会社は破産して管財へ。
    - HWは合計に常に +50M。

    ### 7.2 分配と株価

    社長は以下から選ぶ。

    - 全留保: 利益全額を会社へ
    - 半配: 半分を会社、半分を株主へ
    - 全配: 全額を株主へ

    配当端数は株主有利に切り上げ。プレイヤーが持っていない株の配当は銀行に残る。

    株価調整:

    | 分配額 | 株価 |
    |---|---|
    | 留保、または利益0 | 1段階下落 |
    | 0超、現在株価未満 | 変化なし |
    | 現在株価以上、2倍未満 | 1段階上昇 |
    | 2倍以上、3倍未満 | 2段階上昇 |
    | 3倍以上 | 3段階上昇 |

    株価マーカーは移動後、同じマスの既存マーカーの下に置く。

    ### 7.3 鉱山購入

    - ORごとに最大1鉱山。
    - プレイヤー所有の開いている個人鉱山: 所有者同意が必要。価格は1M以上、額面の2倍以下。
    - 銀行の閉鎖鉱山: 額面で購入。
    - 他の公開鉱山会社からは購入不可。
    - 購入鉱山の資金、machine、switcherはそのまま移る。
    - 閉鎖鉱山を購入した場合、固有の1-machineのみで再開。
    - 保有上限:
      - 50%株会社: 2鉱山
      - 20%株会社: 4鉱山
      - 10%株会社: 5鉱山
    - HWはVor-Harzer鉱山のみ購入可。

    ### 7.4 machine / switcher

    - machineは銀行からのみ購入。
    - 新machineは、会社の少なくとも1つの既存machineより大きいサイズでなければならない。
    - サイズn machineを買うと、最大n個のサイズn machine markerを得て、より小さい既存machineを置換できる。
    - switcher保有上限は所有鉱山数。
    - switcherは銀行または他社から購入可。価格・維持費処理は個人鉱山と同じ。
    - switcherは無料廃棄可。

    ### 7.5 新株発行

    条件: 既発行株がすべてプレイヤー所有。

    - 50%株会社は20%株会社へ。20%株を3枚発行。
    - 20%株会社は10%株会社へ。10%株を5枚発行。この場合、社長が20%株2枚以上、つまり40%以上を持つ必要がある。
    - 新株はInitial Offeringに置く。後に購入された時、代金は会社へ入る。


    ## 8. 鉄道会社のOR

    順序:

    1. 線路敷設
    2. 駅トークン配置
    3. 列車運行
    4. 収益計算
    5. 利益分配
    6. 株価調整
    7. train/switcher購入・廃棄
    8. 新株発行

    ### 8.1 線路敷設

    #### 初運営

    - concession routeを持つ会社は、初ORでroute全体を完成させなければならない。
    - 必要な全タイルを1回の建設アクションで置く。
    - route総建設費を全額支払う。過去に他社が一部建設費を払っていても全額支払う。
    - 初ORでは、concession route完成以外の追加敷設は不可。ただしrouteが既に完成済みなら通常敷設可。

    #### 初運営後

    - 1ORに最大2タイルを敷設/アップグレード可。
    - 2タイル可能なのは、黄タイル、または価値を上げない特定の緑タイル（#75-79、#956-961、#964-970）に限る。
    - それ以外のアップグレードは通常1枚。

    #### 一般制限

    - 黄は未敷設の薄緑/薄茶ヘクスへ。WBEの薄茶routeヘクスC10/C12/C14はフェイズ3から。
    - 緑は黄タイル置換または黄プリントヘクスへ。
    - 茶は緑タイル置換または緑プリントヘクスへ。
    - 灰は茶タイル置換。
    - 新しく作られる線路はすべて、その会社の駅トークンから到達可能でなければならない。
    - 国営路線はrouteに含められない。
    - 茶色の太い地形障壁やマップ外へ線路を出してはならない。
    - 駅/村/町の種類とタイル種類は一致させる。
    - 既存線路や接続を切ってはならない。
    - 建設費はそのヘクスに初めてタイルを置く時だけ。以後のアップグレードでは不要。

    ### 8.2 concession route上の敷設

    - 他社の未完成concession routeヘクスに敷く場合:
      - そのroute部分そのものを敷く、または
      - route完成を妨げない敷き方にする。
    - 必要なら将来route完成用のタイルを予約する。
    - 建設費を支払った場合、建設会社の社長が銀行から同額を個人資金として払い戻される。
    - 自社concession route建設では払い戻しなし。
    - concession route上の駅トークンは、その会社のroute運行時に常に通過可能。ただし他社トークンで完全ブロックされた村/町・鉱山・工場の収益は得られない。

    ### 8.3 駅トークン

    - 浮上時、ホーム駅は無料で全て配置。
    - OR中は最大1駅を建設。
    - 空き駅円への配置: 100Mを銀行へ。
    - 他社の非活性駅トークン置換: 50Mを相手会社へ。同意不要。置換されたトークンは相手会社へ戻る。
    - 新駅は自社の既存駅から到達可能でなければならない。
    - 1社1ヘクス1駅まで。
    - 未運営会社のconcession route上の村には、その会社が初ORで駅を置ける余地を潰す駅建設は不可。
    - 駅トークンは任意除去不可。

    ### 8.4 列車運行

    - 標準trainがある場合、全列車のrouteを決める。switcherは鉄道会社では収益を生まない。
    - routeの端点は、自社駅トークン、開いている鉱山、工場のいずれか。
    - 各routeは少なくとも1つの自社駅トークンを含む。
    - 他社駅で完全ブロックされた町/村は通過も終端も不可。ただし自社concession routeは例外的に通過可。
    - routeは町ヘクス（紫枠）に入ったらそこで終端。
    - 同じroute内で同じ町/村ヘクスを複数回含めない。
    - n trainは最大n routeを運行可。そのn routeは直接または間接に接続したネットワークでなければならない。
    - 2つの未接続駅円がある村でroute同士が「会う」だけでは、route接続とはみなさない。
    - 別train同士のネットワークは接続していなくてよい。
    - 自社concession routeは必ず標準trainで運行する。diesel railcarだけでは不可。
    - NWEのconcession routeは2つの接続route扱い。2列車以上1本で全体を運行するか、2本のtrainで片方ずつ運行する。
    - 同じ会社の標準train route同士は線路を共有できない。町/村で交差・接触することは可。
    - 可能な限り多くのrouteを、可能な限り遠くまで運行する必要がある。ただし収益最大化義務はない。
    - 運行ネットワークに含まれた自社駅はactive面へ。それ以外はinactive面へ。ただし自社concession route上の駅、特にホーム駅はinactiveにならない。

    ### 8.5 diesel railcar

    - フェイズ5の最初のフル3ORセット開始後に購入可能。
    - 各鉄道会社1台まで。
    - diesel railcarのrouteは旅客扱いで、端点は必ず自社駅トークン。
    - 自社concession routeを必ず運行し、そこに接続する任意数の追加routeを運行できる。
    - QLBの場合はQuedlinburgを少なくとも1routeの端点にする。
    - diesel railcarのroute同士も、交差・町/村での接触は可。ただし線路共有は不可。
    - 標準trainのrouteとは独立に追加収益を生む。
    - diesel railcarは廃棄不可。

    ### 8.6 鉄道収益

    収益は以下の合計。

    - 標準trainが運行した自社駅の町/村価値。各駅は1回だけ。
    - 自社駅のない町/村stop: 各10M。各stopは1回だけ。
    - 他社トークンで完全ブロックされた村: 0M。
    - diesel railcarが運行した駅/stop: 各10M。標準train収益に追加。
    - 標準trainが運行した開いている鉱山: 鉱山倍率（10/20/30） x その鉱山に到達した最大trainサイズ。各鉱山は1回だけ。
    - 標準trainが運行した工場: 記載価値。trainサイズは関係なし。各工場は1回だけ。
    - 閉鎖鉱山、他社トークンでブロックされた鉱山/工場は0M。
    - 維持費を差し引いて利益を求める。維持費不足を会社資金で払えなければ破産。

    ### 8.7 分配・株価

    公開鉱山会社と同じ。

    ### 8.8 train / switcher

    - 初ORではcompulsory trainを必ず買う。QLBは例外。
    - compulsory trainは最初の購入でなければならない。switcherやdiesel railcarはその後。
    - NWEは1-trainをcompulsory trainにできない。
    - compulsory train購入直後、concession所有者の特権と義務は終了し、concessionはゲームから除去。必要なら社長交代を判定。
    - train/switcherは銀行から額面購入、または他社から1M以上・額面2倍以下で購入可。
    - switcherは鉱山会社からも購入可。
    - 標準trainとswitcherの保有数制限なし。
    - diesel railcarは1社1台。
    - 最後の標準trainは廃棄・売却不可。NWEは少なくともサイズ2以上の標準trainが必要。
    - train/switcher廃棄は無料。廃棄されたものはゲーム外。
    - diesel railcarは廃棄不可。

    ### 8.9 新株発行

    - 20%株会社が10%株会社になる時だけ。
    - 条件: 既発行株がすべてプレイヤー所有、かつ社長が40%以上所有。
    - 10%株5枚をInitial Offeringへ。
    - 会社は追加駅トークンを受け取る。
    - 後に新株が買われると代金は会社へ。


    ## 9. QLB特別ルール

    - QLBにはconcession routeがなく、ホーム駅はQuedlinburgのみ。
    - built-in compulsory trainを持ち、これは売却不可。
    - local trainは標準train扱いだが維持費は発生しない。
    - local trainはQuedlinburgヘクスだけを運行し、Quedlinburgの価値を収益にする。
    - QLB初ORのtrain購入ステップ開始時に、concession除去と必要なら社長交代を判定する。
    - 追加標準trainはQuedlinburgへ行かなくてもよい。
    - 追加標準trainがQuedlinburgを運行した場合、例外的にQuedlinburg価値をlocal train分と追加train分で2回数える。
    - diesel railcarは必ずQuedlinburgを運行する。


    ## 10. MHE運営

    - MHEは各ORの最後に運営。
    - 行うことは配当と、条件付きtrain購入のみ。
    - 配当総額は所有trainサイズ x 100M。1株あたり10M/20M/30M/40M/50M。
    - 配当後、通常ルールで株価調整。
    - 各ORセットの最終ORに、銀行から無料で標準trainを1本購入して旧trainを除去する。同サイズでも購入扱いで、フェイズ進行を起こしうる。
    - 5-trainを得たら以後train購入なし、株価も固定。
    - MHEはswitcher/diesel railcarを買わない。
    - 他社はMHEからtrainを買えない。
    - MHEは維持費を払わない。


    ## 11. 管財と破産

    流れ: 管財入り条件を満たす → 必要なら再資本化 → 管財会社として運営継続 → ARでpurchase optionが競られ、次SRで株購入されると復帰。

    管財入り条件:

    - 会社が破産した。
    - 形成済み公開会社について、誰も20%以上の株を保有していない。

    ### 11.1 破産する場合

    - 鉄道会社がcompulsory trainを買えない。
    - 収益が維持費を下回り、不足分を会社資金で払えない。

    鉄道会社がcompulsory trainを買えず破産する場合、株価を1段階下げてから再資本化。維持費不足による破産では、この事前下落はない。

    ### 11.2 再資本化の要点

    - 全株主は同社株を無償で銀行へ返す。株はBank Poolへ。
    - Initial Offeringに残株があればBank Poolへ移し、会社はその株数分の現在株価を資金として受け取る。
    - 必要なら株式分割を進めて追加株をBank Poolへ出し、会社へ資金を入れる。
    - それでも不足する場合、銀行が必要額を補助する。補助額が現在株価以上なら、配当と同様の基準で株価が上がる。
    - 鉄道会社は必要な標準trainを買い、維持費対象の標準train/switcherを除去。
    - 公開鉱山会社は維持費対象のobsolete machineを必要数だけ置換し、維持費対象switcherを除去。
    - 再資本化後、破産状態は解消するが管財は継続。その会社の今回ORは終了。

    ### 11.3 管財会社の運営

    公開鉱山会社:

    - 通常どおり生産。
    - 利益は必ず留保。ただし株価は下がらない。
    - 維持費不足なら再資本化。
    - 新鉱山・switcherは買わない。
    - 再資本化時を除き、新machine購入・新株発行もしない。

    鉄道会社:

    - 線路も駅も建設しない。
    - concession routeを最大標準trainで運行する。
    - 最大標準trainが2以上かつNWEでない場合、concession routeに接続する最高収益routeを追加で運行する。
    - その列車が3以上なら、以後も可能なrouteを最高収益順に追加する。追加列車もサイズ降順で同様に選ぶ。同収益ならランダムに選ぶ。
    - diesel railcarを持つ場合は通常どおり追加運行する。
    - 利益は必ず留保。ただし株価は下がらない。
    - 維持費不足なら再資本化。
    - 新switcherは買わない。
    - 再資本化時を除き、新train購入・新株発行もしない。

    ### 11.4 管財からの復帰

    - 管財会社の株は通常購入不可。
    - AR開始時、管財会社ごとにpurchase optionを競売可能。
    - 落札者は次のSRで20-40%を一括購入して復帰させる。50%株会社なら50%株1枚を購入。
    - 行使しなかったpurchase optionは没収される。


    ## 12. 終了条件と勝利

    ゲームは以下のいずれかで終了。

    - いずれかの会社の株価が1000に到達。現在OR終了後に終了。
    - フェイズ5開始後、2回目の3ORセットが終了。即終了。

    勝利点は個人資産。

    - 現金
    - 保有株の現在価値
    - 個人所有の独立鉱山の額面

    公開鉱山会社が所有する鉱山の額面は、プレイヤー個人資産には直接加えない。

    ## 用語メモ

    - concession: 鉄道会社を設立する権利。落札したconcessionは、続くSR中に会社設立に使わないとSR終了時に没収される。
    - active concession: ARで競売対象にできる状態のconcession。駅トークンのactive/inactiveとは別概念。
    - active/inactive駅トークン: 鉄道会社が直前の運行で使った駅はactive、使わなかった駅はinactiveになる。自社concession route上の駅はinactiveにならない。
    - compulsory train: 鉄道会社が初ORで必ず買う標準train。購入後にconcession所有者の特権が終わり、必要なら社長交代を判定する。
    - PMC: Public Mining Company、公開鉱山会社。


    ## 0. ラウンド構成

    - ゲームは **TR（Trading Round）** と **OR（Operating Round）** を交互に行う。
    - 各TRは **AR（Auction Round）→ SR（Stock Round）** の順。
    - ゲーム開始時のTRは、通常ARではなく **Start Auction Round**。
    - TR後に行うOR数はフェイズで決まる。フェイズ1-2は1OR、フェイズ3-4は2OR、フェイズ5/Dは3OR。
    - OR順:
      1. 個人鉱山: 額面の昇順
      2. 公開鉱山会社・鉄道会社: 株価の降順。同値なら株価マーカーが上にある会社から
      3. MHE: 常に最後


    ## 5. フェイズ、列車、機械、維持費

    ### 5.1 列車・機械・switcher

    | サイズ | 数 | machine価格 | train価格 | switcher価格 |
    |---:|---:|---:|---:|---:|
    | 1 | 1 | - | 100 | - |
    | 2 | 10 | 150 | 250 | 50 |
    | 3 | 7 | 300 | 450 | 100 |
    | 4 | 3 | 500 | 750 | 150 |
    | 5 | 無制限 | 800 | 1200 | 200 |
    | D | 7 | - | 250 | - |

    - 1-machineは全鉱山が初期装備として持つ。追加購入できるサイズ1ユニットは1-trainのみ。
    - サイズ2以上のユニットは、購入時にmachineまたはtrainとして選ぶ。
    - 次サイズは、現サイズのtrain/machineが全て購入されるまで出ない。
    - switcherはtrain/machineの枚数を消費しない。
    - サイズnのswitcherは、最初のサイズn train/machine購入後に利用可能になり、次サイズのtrain/machine購入で終了する。5-switcherは最後まで。
    - machineは鉱山会社のみ。trainとdiesel railcarは鉄道会社のみ。switcherはどの会社も所有可。

    ### 5.2 所有・収益早見表

    | 種類 | 所有できる会社 | 収益を生む場所 | 注意 |
    |---|---|---|---|
    | machine | 個人鉱山、公開鉱山会社 | 鉱山会社の生産 | 他社売買不可。任意廃棄不可 |
    | train | 鉄道会社 | 鉄道会社のroute収益 | 最後の標準trainは売却/廃棄不可 |
    | switcher | 全会社 | 鉱山会社の生産 | 鉄道会社も所有できるが収益なし |
    | diesel railcar | 鉄道会社 | 駅/stopごとに追加10M | 1社1台。廃棄不可 |

    ### 5.3 フェイズ表

    | フェイズ | 開始条件 | OR数 | タイル | 維持費 | 主な効果 |
    |---|---|---:|---|---|---|
    | 1 | ゲーム開始 | 1 | 黄 | なし | HBE/GHE active。HWはSR1設立可 |
    | 2 | 初の2 train/machine購入 | 1 | 黄 | なし | NWE/SHE/KEZが条件活性化可。2-switcher |
    | 3 | 初の3 train/machine購入 | 2 | 黄・緑 | 1-machine 50、1-train 50 | NWE/SHE/KEZ未活性ならactive。WBE条件活性化可。3-switcher |
    | 4 | 初の4 train/machine購入 | 2 | 黄・緑 | 1-machine 100、2-machine 50/鉱山、1/2-train 100、2-switcher 20 | WBE未活性ならactive。QLB active。4-switcher |
    | 5 | 初の5 train/machine購入 | 3 | 黄・緑・茶 | 1-machine 100、2-machine 50/鉱山、1/2-train 100、2-switcher 20 | 5-switcher。Dは次のフル3ORセット開始後から購入可 |
    | D | 初のdiesel railcar購入 | 3 | 黄・緑・茶・灰 | 1-machine 150、2-machine 100/鉱山、3-machine 50/鉱山、1/2/3-train 150、2-switcher 50、3-switcher 30 | 5 train/machineは継続 |

    フェイズ効果は即時。ただしTR間のOR数だけは、次のORセットから変わる。

    diesel railcarの購入可能タイミング例: OR2/3中に初の5 train/machineが買われてフェイズ5になった場合、そのORセット中にはdiesel railcarはまだ買えない。次TR後の、最初から3ORあるORセット開始時から購入可能。

    ### 5.4 収益計算早見表

    | 対象 | 基本式 | 維持費不足時 |
    |---|---|---|
    | 個人鉱山 | 未接続なら基礎収益。接続済みならmachine欄 + switcher欄 | 鉱山資金で払えなければ閉鎖 |
    | 公開鉱山会社 | 所有鉱山それぞれの収益合計。HWはさらに+50M | 会社資金で払えなければ破産/管財 |
    | 鉄道会社 | 駅/stop/鉱山倍率 x trainサイズ/工場/diesel追加収益の合計 | 会社資金で払えなければ破産/管財 |

    ## 15. 初期戦略メモ

    ### HW戦略

    - \#12取得が鍵。SR1でHWを設立できる唯一の権利。
    - もう1つ安めのVor-Harzer鉱山を確保し、初期株価を過度に高くしない。
    - 長期的には追加のVor-Harzer鉱山を2-3個取り込みたい。
    - \#14、#11、#10は後でHWに高値売却しやすい候補。
    - \#4/#5/#6は安めの基盤候補。

    ### 公開鉱山会社（PMC）戦略

    - 強いPMCには4-5鉱山が欲しい。
    - 5鉱山運用には10%株化が必要になるため、4鉱山で柔軟性を残す選択も有効。
    - 初期株価は高すぎず低すぎず、180-220前後が扱いやすい。
    - 接続済み、または早く接続される鉱山を重視する。PMC自身は線路を敷けない。
    - \#15は開始時接続済み。#12はHBE、#13はGHEで接続されやすい。
    - \#4/#5/#6/#10はHBE次第。#3/#7はGHEで接続されやすい。
    - \#8/#9/#14はNWE/SHE/KEZ待ちになりやすく、自力敷設で早期活性化を狙うことがある。

    ### HBE戦略

    - HBEは有望だが、浮上に3株分の現金が必要。
    - 初期株価120/150/190なら、浮上に360/450/570M必要。
    - Blankenburg-D15からElbingerode-D9方面の「稼ぐ線」を開けるため、#10と#4/#5/#6のうち少なくとも2つが開いていると強い。
    - 他プレイヤーが鉱山を買わないなら、支援PMC用に鉱山を買って閉鎖を防ぐ選択がある。

    ### GHE戦略

    - 序盤の収益はHBEより限定的になりやすい。
    - 初期株価120/150なら、浮上に360/450M。
    - \#3/#7/#13のうち少なくとも2つが開いていると立ち上がりが安定。
    - 株需要がHBEほど高くないため、社長が高比率を握れる展開もある。


    ## 16. よく忘れるチェック

    - concessionを落札したSRで鉄道会社を設立しなければ、そのconcessionはSR終了時に没収。
    - purchase optionも同じSRで行使しなければ没収。
    - 未運営鉄道会社の社長は、compulsory train購入または破産まで交代しない。
    - 公開鉱山会社は線路を敷けない。
    - 個人鉱山と公開鉱山会社のmachineは他社売買不可。
    - switcherは鉄道会社も買えるが、鉄道会社では収益を生まない。
    - 鉱山収益は「鉱山会社の生産」と「鉄道会社のroute収益」で計算方法が違う。
    - 鉄道会社の鉱山収益は、鉱山倍率 x 到達した最大標準trainサイズ。
    - diesel railcarはconcession route運行義務を代替しない。
    - MHEの無料train更新はフェイズを進めうる。
    - フェイズ進行時、維持費は即時有効。ただしOR数変更は次のORセットから。
